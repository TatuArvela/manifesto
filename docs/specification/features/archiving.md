# Archiving

You can archive a note. This removes the note from the main view, but it does not delete the note.

## Behavior

- Archive a note from the note card or from the editor toolbar.
- An archived note goes out of the main Notes view. The card moves up and off the board.
- When you unarchive a note from the Archive view, the card moves out in the same way as when you
  restore a note from the trash.
- To see the archived notes, open the Archive view in the sidebar.
- When you restore an archived note, it goes back to the main view.
- Archiving does not change the content, tags, color, or other metadata of the note.
- Archiving sets `archived: true` on the note (see [Data Model](../data-model.md)).
